# Code of Conduct

## Our standard

The HRIS Framework welcomes researchers, practitioners, contributors, and readers from different backgrounds. Participation should be thoughtful, evidence-oriented, and respectful.

Expected behavior includes:

- engaging with ideas and evidence rather than attacking people;
- giving constructive feedback and acknowledging uncertainty;
- respecting privacy, consent, attribution, and intellectual property;
- avoiding harassment, discrimination, intimidation, and unwanted personal contact;
- keeping research discussions relevant and professionally appropriate.

## Scope

This code applies in repository issues, pull requests, discussions, and other project-managed spaces. It also applies when someone represents the project publicly.

## Reporting

Report conduct concerns privately to drjustinhudson@gmail.com. Do not disclose sensitive details in a public issue.

Reports will be reviewed fairly and with appropriate confidentiality. Project maintainers may edit or remove contributions, limit participation, or take other proportionate action when this standard is violated.
