# HRIS Research Starter Kit

Run a small, structured HRIS-inspired observation in approximately 20–30 minutes. This kit is designed for researchers, designers, educators, and curious practitioners exploring how interaction history may shape subsequent human–AI behavior.

## What is included

- [20-minute experiment](EXPERIMENT.md) — a guided comparison between a history-conditioned interaction and a fresh-session control.
- [Observation worksheet](OBSERVATION-WORKSHEET.md) — questions for recording shorthand, corrections, constraints, and reconstruction.
- [Results template](results-template.csv) — a simple table for structured observations across trials.
- [Citation guidance](../CITATION.cff) — project-level citation metadata.
- [Framework diagrams](../diagrams/) — visual introductions to ISS, SIBR, and TAS.

## Quick start

1. Choose one AI system and one modest task that can be repeated.
2. Open two separate sessions: **History-conditioned** and **Fresh control**.
3. Follow the stages in [EXPERIMENT.md](EXPERIMENT.md).
4. Record observations in the worksheet or CSV template.
5. Repeat before drawing conclusions.

## What this can and cannot show

This activity is an exploratory demonstration, not a validated diagnostic instrument. It can help identify candidate patterns for controlled study, but a single trial cannot establish persistent identity, consciousness, memory, or causal mechanism.

## Share a result

If you adapt the kit, cite the HRIS Framework and describe the model, date, task, session conditions, and changes you made. Do not include private conversations or identifiable participant information without appropriate permission.
