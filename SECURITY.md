# Security Policy

## Supported versions

Security fixes apply to the current default branch and the latest published release.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting feature for this repository. Include:

- a description of the issue and its potential impact;
- the affected file, page, or release;
- steps to reproduce the problem;
- any suggested mitigation, if known.

If private reporting is unavailable, contact the maintainer at drjustinhudson@gmail.com with the subject “HRIS security report.”

Reports will be acknowledged as soon as practical. Please allow reasonable time for investigation and remediation before public disclosure.
